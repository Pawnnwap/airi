# Haru — Live2D stage model (sample asset)

`Haru.zip` in this folder is the official **Haru** sample model from
[Live2D/CubismWebSamples](https://github.com/Live2D/CubismWebSamples)
(`Samples/Resources/Haru`), served locally so the stage-web import flow can
fetch it in browser automation and offline setups.
